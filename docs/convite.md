# Convite para o LinkedIn

Novo projeto de QA Automation no GitHub!

Estou desenvolvendo o Robot Framework ServeRest CRUD, um projeto de automação de testes de API utilizando Robot Framework e Python.

O objetivo é validar as principais operações de gerenciamento de usuários (CRUD), autenticação e contratos de API, aplicando boas práticas de automação e validação de respostas HTTP.

O que você encontrará no projeto?

- Testes de API com Robot Framework.
- Operações de Create, Read, Update e Delete (CRUD).
- Testes de autenticação.
- Validação de contratos e estruturas JSON.
- Asserções de status HTTP e consistência dos dados.
- Organização e reutilização de keywords para facilitar a manutenção dos testes.

O projeto é um template para sua jornada de aprendizado e evolução contínua em Qualidade de Software e automação de testes.

Confira o repositório no GitHub: https://github.com/horadoqa/robotframework-serverest-crud

Este projeto tem pontos de melhoria e pode evoluir para atender a cenários mais complexos e escalar conforme as necessidades. É apenas um START, com muito espaço para aprendizado e evolução contínua!
