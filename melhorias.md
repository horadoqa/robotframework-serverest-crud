## Melhorias recomendadas para um projeto profissional

Depois de fazer a primeira execução, vale evoluir o projeto com:

- Testes negativos: e-mail duplicado, campos obrigatórios ausentes, usuário inexistente e payload inválido.
- Independência dos testes: criação e exclusão dos dados em cada caso de teste.
- Variáveis de ambiente: separar URL e configurações entre ambientes.
- CI/CD: executar os testes automaticamente em GitHub Actions.
- Evidências: armazenar relatórios e resultados de cada execução.
